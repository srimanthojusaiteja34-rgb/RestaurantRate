
# RestaurantRate – Scan & Rate

A mobile-friendly restaurant food menu and rating platform.

## Features
- Dark theme interface
- Food photographs
- Food search
- Food category filters
- Five-star food ratings
- Restaurant QR code generation
- QR code camera scanner
- Local browser storage

## Technologies
- HTML5
- CSS3
- JavaScript
- QRCode.js
- HTML5 QR Code
- Firebase (planned)

## Project Structure

RestaurantRate/
- index.html
- style.css
- script.js
- firebase.js
- README.md

## How to Run
1. Open index.html.
2. Ensure internet access for food images and QR libraries.
3. Allow camera permission when using the scanner.

## Project Status
Frontend prototype.

Firebase integration and online deployment are pending.
